# Тренажёр дорог: Грозный и Чечня

Учебный тренажёр для начинающего водителя: укажите свой дом, смотрите маршруты по шагам и проходите тесты «Как доехать?» и «Где это?». Карты и маршруты — Яндекс Карты (нужен бесплатный ключ JavaScript API, вводится при первом открытии и хранится только в браузере).

Тренажёр — для подготовки дома. За рулём пользуйтесь навигатором.
